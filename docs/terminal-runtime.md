# 终端运行时重构

## 事件与协议

本地 PTY 和 SSH 都保留 Alacritty 解析器事件接收任务。SSH 每解析一块输出就立即
消费已生成的协议事件，再解析下一块，避免将设备属性、光标位置、颜色和尺寸查询
响应丢弃或跨输出块乱序；标题、剪贴板和闪烁控制同样经过此通道。

解析器接收端由共享包装器持有，异步事件任务负责等待，本次解析后的同步消费不会
持有锁执行终端回调。SSH 重连替换网络事件任务，但保留解析器通道。

SSH 事件按已就绪的数据批量送入一次 UI 更新，每批最多 64 条，并在约 128 KiB
字节预算后停止收集（允许最后一个至多 32 KiB 的数据块越界）。不等待凑满一批，
处理后主动让出执行机会。重绘通知按批次合并。VT 解析仍在 UI 线程执行。

## 背压与退出

每条 SSH 连接的待消费输出预算为 1 MiB，按不超过 32 KiB 的块发送。
`SshEvent::Data` 使用 `SshOutput`，通过 `Deref<Target = [u8]>` 读取字节。
数据和额度由所有克隆共享，最后一个消费者释放数据后归还额度；输出不会被丢弃。
消费者长期持有输出会暂停继续投递，调用方应及时处理并释放。

主动断开或丢弃会话会关闭额度信号量，解除等待，避免输出队列满时阻塞退出。
该预算限制应用事件队列，不包括 SSH 库、协议窗口和网络缓冲自身的空间。

光标任务由视图持有，销毁视图时取消，实体更新失败时退出；未聚焦、禁止闪烁、
已退出或全屏 TUI 使用固定光标时不产生闪烁重绘。远端闪烁控制事件也会更新视图。

## 同步更新与渲染缓存

SSH 解析器检查同步更新截止时间，并持有独立的超时任务。
连续输出时检查超时；静默等待时定时结束未关闭的 `CSI ? 2026 h` 更新。
重连取消旧定时任务并重置解析器。

终端快照在输出、内部交互命令、配置或相关后端事件变化时更新。
纯光标闪烁复用已有快照，快照更新复用 cell Vec 容量。

视图保留上一帧可见行布局；未变化的行复用背景、批量文本 run 和块字符布局。
缓存比较完整单元格、显示行位置、悬停链接、渲染配置与裁剪区域。
滚动、调整尺寸、字体/主题更新及悬停变化按这些条件使缓存失效。
选区和搜索高亮独立绘制。缓存限于当前视口，不积累无限历史行。
GPUI 仍负责文字整形与绘制；这里不宣称减少 GPU 绘制区域或固定百分比的性能收益。

## 验证

```sh
cargo check --locked --workspace
cargo test --locked -p ssh
cargo test --locked -p alacrterm
cargo test --locked -p terminal --lib
```

本次终端全量测试为 48 项通过、23 项失败；失败集中在重构前已有的路径超链接
正则匹配测试。本次新增的快照复用、协议响应和同步更新测试均通过。
排除路径匹配组后为 47 项通过（该组还包含一个通过的测试）。

隔离 Xvfb GUI 与本地 SSH 服务验证了：会话编辑/取消、正常退出后重连、网络中断、
失败重试、服务恢复、SFTP 目录读取、远端光标/颜色查询响应、未结束同步更新超时。
共享 WayX 的实际压缩 X11 转发与启停重启测试也通过。

GUI 验证使用 Linux；Windows/macOS 尚需原生运行验证。性能收益未进行跨平台量化。
